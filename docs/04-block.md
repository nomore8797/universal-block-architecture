# 04. Block / Блок

## English

A block is an autonomous computational unit that:

- accepts input data  
- performs analysis  
- produces an interpretation  
- emits a result that can be attached to the linkage  

### Internal Structure

Input  
↓  
Analysis (based on analytical parameters)  
↓  
Interpretation (individual yet deterministic)  
↓  
Output:  
- “Analysis completed”  
- “Conclusion based on analysis”

### Properties

- Autonomy — independence from other blocks  
- Versionability — any change creates a new version  
- Determinism of interpretation — identical analytical parameters yield identical interpretations  
- Attachability — the result can be cryptographically bound to the linkage  

### Explicit Non-Responsibilities

- Knowledge of other blocks  
- Management of transport  
- Participation in consensus decisions  
- Storage of global history

## Русский

Блок — автономная вычислительная единица, которая:

- принимает входные данные  
- выполняет анализ  
- формирует интерпретацию  
- выдаёт результат, который может быть пристёгнут к сцепке  

### Внутренняя структура

Вход  
↓  
Анализ (на основе аналитических параметров)  
↓  
Интерпретация (индивидуальная, но детерминированная)  
↓  
Выход:  
- «Анализ данных завершён»  
- «Вывод на основе анализа»

### Свойства

- Автономность — независимость от других блоков  
- Версионируемость — любое изменение создаёт новую версию  
- Детерминированность интерпретации — одинаковые аналитические параметры дают одинаковые интерпретации  
- Пристёгиваемость — результат может быть криптографически связан со сцепкой  

### Явные не-ответственности

- Знание о других блоках  
- Управление транспортом  
- Участие в решениях консенсуса  
- Хранение глобальной истории

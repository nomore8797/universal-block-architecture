# 02. Overview / Обзор

## English

Universal Block Architecture is a method of constructing complex systems from autonomous blocks, where inter-block connections are secured by a cryptographic linkage.

The platform operates as a constructor:
- Select blocks
- Connect them via linkage
- Obtain verifiable data flows and interpretations

Most existing systems intertwine computation, meaning, movement and history.  
UBA enforces a strict separation of these layers.

Consequences of the separation:
- Analysis can be scaled independently
- Transport can be replaced independently
- Linkage can evolve independently
- The origin of any interpretation can be cryptographically proven

The architecture is particularly relevant for domains that require data lineage, auditability of conclusions, and high composability.

## Русский

Universal Block Architecture — это метод построения сложных систем из автономных блоков, в котором межблоковые связи обеспечиваются криптографической сцепкой.

Платформа работает как конструктор:
- Выбираются блоки
- Соединяются посредством сцепки
- Получаются верифицируемые потоки данных и интерпретаций

Большинство существующих систем смешивают вычисление, смысл, перемещение и историю.  
UBA устанавливает строгое разделение этих слоёв.

Следствия разделения:
- Анализ может масштабироваться независимо
- Транспорт может быть заменён независимо
- Сцепка может эволюционировать независимо
- Происхождение любой интерпретации может быть криптографически доказано

Архитектура особенно релевантна для областей, требующих data lineage, аудита выводов и высокой композируемости.

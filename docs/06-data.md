# 06. Data / Данные

## English

### Data Categories

1. Input data — raw material entering the block  
2. Analytical parameters — the basis for analysis  
3. Analysis result — “Analysis completed”  
4. Interpretation — “Conclusion based on analysis”  
5. Linkage metadata — information recorded by the linkage  

### Primary Flow

Input data  
→ Block (Analysis → Interpretation)  
→ Attachment to linkage  
→ (optional) Transport to subsequent block

### Audit Flow

Any interpretation  
→ Linkage  
→ Verifiable provenance history

### Governing Rule

Data may flow freely.  
Meaning (interpretation) remains permanently bound to the specific block that produced it via the linkage.

## Русский

### Категории данных

1. Входные данные — сырой материал, поступающий в блок  
2. Аналитические параметры — основание для анализа  
3. Результат анализа — «Анализ данных завершён»  
4. Интерпретация — «Вывод на основе анализа»  
5. Метаданные сцепки — информация, фиксируемая сцепкой  

### Основной поток

Входные данные  
→ Блок (Анализ → Интерпретация)  
→ Пристёгивание к сцепке  
→ (опционально) Транспорт к следующему блоку

### Аудиторский поток

Любая интерпретация  
→ Сцепка  
→ Верифицируемая история происхождения

### Управляющее правило

Данные могут перемещаться свободно.  
Смысл (интерпретация) остаётся постоянно привязанным к конкретному блоку, который его породил, через сцепку.
